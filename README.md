# latex-semapinho

Este pacote permite a inserção de semapinhos (o mascote da [Semana da Matemática Aplicada do IME-USP](https://semap.ime.usp.br)) como elemento de texto e como símbolo em equações.

Semapinho em LaTeX:
```tex
\semapinho
```

Para usar por fora, é só colocar os arquivos `semapinho.sty` e `semapinho.png` no seu projeto e adicionar
```tex
\usepackage{semapinho}
```
que vai dar certo.
